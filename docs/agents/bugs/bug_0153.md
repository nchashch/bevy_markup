## Root cause and fix
Units mixed: the build compared `computed.size.x` (the root's border box,
physical px) with `model.width` (the logical content width), which agree
only for an unpadded, borderless root at scale 1 — otherwise the model
cleared on every build and the UI rebuilt every frame. The band used the
physical height as the viewport and ignored the root's top padding; the
measurement scaled the (logical) margins by the inverse factor. Fix: one
unit system — logical pixels of the root's content box
(`logical_content_width`), the visible region = the padding box
starting `padding-top` above the content (`visible_region`), only the
measured size converted. `77086c8`'s HiDPI fix converted the heights but
left the rest.
