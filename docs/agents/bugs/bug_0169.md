## Root cause and fix
ADR 0021's skip refreshes a reused root's `DomNode` when its handle
moved, but not its `WindowKey`. A paragraph after a removed row kept the
handle that now names the section after it; on the next measurement its
height and its opaque mark (a text node lays out as a row) landed on that
section. The section's frame stopped culling, and the section reused
whole the spec of a frame that had built everything. Fix: the skip
writes the key with the handle. The property now checks that no two
entities share a key in any frame.
