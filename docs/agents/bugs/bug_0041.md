## Symptoms

A theme swap that drops `html { width: calc(…) }` keeps resolving the old
calc: the root stays at the previous size. And a top-level `HtmlUi` (no
`ChildOf`) never applies root calc at all.

## Root cause

`apply_root` only *inserts* `CalcSized` (never removes it), so the
component outlived its declaration; and `resolve_calc` skipped roots
without a parent, treating the root's own box as the basis.

## Fix

The calc pass removes `CalcSized` when the declaration goes, and a
top-level root resolves against the viewport — the UI camera's target
(preferring the default UI camera), since the root's own box is not the
viewport (an auto-sized root shrinks to its content) (`c07dda7`).
