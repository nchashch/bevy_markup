## Minimal reproduction

Default `a.css` (red); override `broken.css` (falls back to red); set `DefaultStylesheet` to `b.css` (green).

- Observed: Stays red.
- Expected: Rebuild green: the default applies whenever the override isn't usable.

## Root cause

With an override present only `own.is_changed()` and the override's reloads counted, even when the override had failed.

## Fix

The default's swaps/reloads count whenever no *ready* override exists (`default_applies`).
