## Symptoms and repro
Cancelling the dialog with Esc / B left focus to focus repair, which
fell back to the menu's autofocus (Volume) — answering it focused Reset.

## Root cause and fix
Fix: `close_dialog` (shared by both paths) despawns the dialog and
focuses Reset; Esc with no dialog open does nothing.
