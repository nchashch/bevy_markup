## Symptoms and repro
Debug timings: 40k `{{ x }}` lines (320 KB) took 20.1 s in
`resolve_references`; 40k own-line statements in a `.md` 26.3 s and a 1 MB
line of inline statements 40.6 s in `separate_statements`; the outline
built `"  ".repeat(depth)` per node.

## Root cause and fix
Each loop re-ran `find` for every needle over the whole remaining text
per iteration (and a needle that never occurs scanned to EOF every
time). Fix: stop positions cached in absolute coordinates, line starts
cached per line, the outline carrying each node's indent. (The
review_0004 rewrite of `separate_statements` briefly re-broke the
"missing newline" cache — 1.25 s for the 1 MB line — which the scaling
test caught and the old bound did not.)
