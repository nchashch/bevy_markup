## Symptoms

A stylesheet with a flat `calc()` operator chain and **zero** nested parentheses aborts the process with a stack overflow on a 2 MB worker thread (matching Bevy's IO task pool), across mixed-unit additions, multiplications, and single-unit additions alike.

Child-process probes of `bevy_markup::fuzz::cascade` on a 2 MB thread (debug build, `CARGO_PROFILE_DEV_DEBUG=0`), each `p { width: calc(<chain>); }`:

| Chain | Terms | Bytes | Result |
|---|---:|---:|---|
| `1px + 1% + …` (mixed units) | 500 | 2,773 | ok (6.4–8.8 ms) |
| `1px + 1% + …` (mixed units) | 1,000 | 5,523 | ok (14.8–30.0 ms) |
| `1px + 1% + …` (mixed units) | 1,400 | 7,723 | **`SIGABRT` (exit 134): stack overflow** |
| `1px * 1 * …` | 1,000 | 4,023 | ok (1.7 ms) |
| `1px * 1 * …` | 2,000 | 8,023 | **`SIGABRT` (exit 134): stack overflow** |
| `1px + 1px + …` (same unit) | 3,000 | 18,023 | **`SIGABRT` (exit 134): stack overflow** |

## Root cause

`nesting_over_limit` (`src/cascade.rs:1849–1877`) bounds only bracket/paren/brace/function nesting depth, and `MAX_CALC_DEPTH` (32, `src/css/value.rs:535`) increments only on `(` or nested math functions. `parse_sum` (`:461–473`) and `parse_product` (`:494–511`) build left-skewed recursive `Ast::Sum` / `Ast::Mul` / `Ast::Div` chains whose depth equals the operator count.

`evaluate` (`:576–626`) recurses down that spine before any constant folding occurs—so even same-unit chains (`1px + 1px + …`) overflow—and dropping `Ast` / `CalcExpr` also recurses linearly. For mixed-unit sums, `evaluate` additionally invokes `simplify` (`CalcExpr::collapse`) and `expr_is_finite` at every intermediate `Ast::Sum` node (`:597, :622`).

## Fix (proposed)

Enforce a per-expression node/term cap (e.g., 64–256 terms) in `parse_sum`/`parse_product` (or flatten `Ast::Sum`/`Ast::Mul` into length-capped `Vec`s so neither evaluation nor `Drop` recurses linearly with term count). Run `simplify` and `expr_is_finite` once at the top level or iteratively instead of at every intermediate `+`. Add regression tests on a 2 MB thread in debug builds covering mixed-unit `+`, same-unit `+`, and `*` chains.
