## Symptoms

`events.read().any(…)` stopped at the first matching event; a second
matching one in the same frame (a hot reload's `Modified` then
`LoadedWithDependencies`) triggered the resolve next frame — an extra
re-resolve and a second `HtmlUiBuilt`.

## Fix

The event scan folds over all events instead of short-circuiting
(`402362c`).
