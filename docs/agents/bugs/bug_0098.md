## Symptoms and repro
`html_ui::reuse_with_inline_vars_forces_no_extra_restyles` (the revert shows restyled=2)

## Root cause and fix
A reuse build's fresh inline-var scan misses the reused subtrees' names; assigning the smaller set zeroed the vars hash — a full restyle whose complete set differed again forced a second. Reuse builds now union with the previous set.
