## Root cause and fix
Two checks decided whether a frame could be cursor-tracked: the container's
declared layout (`Grid`, `Row`, `Wrap`, non-start packing) and a mark the
measurement set from the laid-out `Node`. Both tested `== Row`, so
`row-reverse`, `column-reverse` and `wrap-reverse` counted as columns; the
root frame was always assumed to be a column. Fix: one predicate,
`children_are_opaque`, true for anything but a non-wrapping, start-packed
column or block, applied to the `Node` the container's declared layout
produces (decided in the build, so a restyle stops the cursor in its own
frame) and to the root's `Node` (a non-column root windows nothing). The
measured marks (`WindowModel::opaque`) are gone: they duplicated the
declared check a frame late, and only ever grew (bug_0171).
