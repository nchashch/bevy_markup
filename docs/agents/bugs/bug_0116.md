## Symptoms and repro
`<input type="">` and `<input type="txet">` built nothing.

## Root cause and fix
`type` had to equal `text` (or be missing); HTML's invalid-value default
is `text`. Fix: only the other known types (`checkbox`, `password`, …)
build no field.
