## Symptoms and repro
`data-l10n-args='{"name": "{{ player }}"}'` (README, quickstart): Tera
escapes `"` as `&quot;`, but `decode_entities` undoes it before the JSON
parse, so `Ada", "extra": "INJECTED` became two arguments.

## Root cause and fix
Hand-written JSON around a spliced value. Fix: build the args with Tera,
which prints maps as JSON with escaped strings — a map literal,
`data-l10n-args='{{ {"name": player} }}'` — in the README, the crate docs
and every example template (15 files); AGENTS.md documents the rule.
