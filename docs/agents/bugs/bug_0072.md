## Symptoms

A signal handler that despawns the UI in a frame where focus also changed
panics: `insert<PseudoState> … Entity despawned`.

## Root cause

`update_focus_states` used a plain `insert`. It and the exclusive
`dispatch_signals` are ordered only against `Render`, not each other, so
dead entities reach the state walk — the bug_0021 class, which fixed the
pseudo-state system but missed this one.

## Fix

`try_insert` instead of `insert` (`cd21ffd`).
