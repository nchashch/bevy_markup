## Symptoms

`grid-template-areas: "x y"` then `grid-template-areas: none` kept the
names and the implied 1×2 tracks. A later nameless
`grid-template-rows`/`-columns` kept the earlier rule's row/column names.

## Root cause

Name registration only ever added; a declaration without names didn't
clear the table it superseded.

## Fix

A nameless `grid-template-rows`/`-columns` clears those names, `none`
clears the areas and their implied tracks, and the
`grid-template`/`grid` shorthands reset the whole table (`6195a88`).
