## Symptoms and repro
`MinimalPlugins + AssetPlugin + ImagePlugin + BevyMarkupPlugin` with
`text-input`: `Encountered an error in system
bevy_ui_widgets::text_input::text_input_autoscroll_system: Parameter
Res<PointerState> failed validation: Resource does not exist`. The tests
and the harness inserted it by hand.

## Root cause and fix
The plugin registered the widget's messages and `UiScale` for headless
apps but not picking's `PointerState`. Fix: `init_resource` it there
(idempotent with a real picking setup).
