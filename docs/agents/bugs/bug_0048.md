## Symptoms

After a theme swap that drops `html { position: fixed }`, the root stays
fixed-positioned; after dropping a `grid-template-areas` rule, the root
keeps the implied `auto` tracks.

## Root cause

`restore_from` restored only `Absolute | Relative` (the comment claimed
fixed was covered), and never restored the `auto` tracks that
`grid-template-areas` implies. `apply_root` then saved the stale state as
the new baseline.

## Fix

`restore_from` undoes `fixed` and the implied tracks (`6195a88`).
