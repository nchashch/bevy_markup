## Minimal reproduction

Root children `div > p#x`, then `p#x`; `by_id(root, "x")`.

- Observed: Returns the shallower second `p#x`.
- Expected: The first in document order, as documented.

## Root cause

Bevy's `Query::iter_descendants` is breadth-first.

## Fix

Use `iter_descendants_depth_first`.
