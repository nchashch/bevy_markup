## Symptoms

A substitution miss (the formatted text no longer splits into the cached
parts) turned into a `Localize` error — the documented fallback is the
per-value conversion. Two bundles/messages sharing an id: the cache kept
the *later* pattern (`insert`) while the Fluent bundle keeps the first,
so the same id converted differently on the two paths.

## Fix

A miss falls back to per-value conversion (`None`, not `Err`), and
duplicate ids keep the first entry — the bundle's own choice (`402362c`).
