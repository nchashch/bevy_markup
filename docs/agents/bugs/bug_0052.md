## Symptoms

`grid-template-columns: 100px 1fr` then `fit-content(2em) 1fr` → the
element has no columns. `row-gap: 8px` then `5%` → no gap.
`width: calc(50% - 10px)` then `fit-content` → no width. Same
`= helper(value)` pattern for display, alignment, padding, and an invalid
side of `border-width`/`padding`. Contradicted the `track_sizing` doc.

## Root cause

The apply helpers cleared the field (or removed the old calc, in
`set_calc`) *before* validating the new value, so an unsupported value
left nothing behind.

## Fix

An unsupported value drops its declaration, keeping the earlier rule's
value (`49525d2`).
