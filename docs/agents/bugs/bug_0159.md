## Root cause and fix
`--exit-after` injects a key press every 40 frames (arrows, Enter, …) so
the examples exercise their branches. `--scenario` pinned the scenario,
but the size wasn't pinned: navigation reached the − / + buttons and
Enter stepped the size. Fix: `--size` pins the size like `--scenario`
pins the scenario.
