## Symptoms

Ending a touch never emits `data-on-leave` for the elements the pointer
had entered, and `hover_signals`' `entered` map grows by one entry per
touch.

## Root cause

Bevy despawns touch pointers on touch end and drops them from the hover
map; the code `continue`d on a pointer missing from `now` instead of
emitting leaves from the previous-frame snapshot.

## Fix

A pointer gone from the hover map emits its leaves from the snapshot and
is dropped from the map (`cd21ffd`).
