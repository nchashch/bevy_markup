## Symptoms and repro
`cargo check --lib --features fuzzing` → `error[E0061]` ×2 at
`src/fuzz.rs:196-197`.

## Root cause and fix
ADR 0028 chunk D (`6efb830`) added an `&ElementState` parameter to
`Styler::style_of`/`box_of`; the feature-gated harness wasn't updated (the
fourth time this class shipped: G03, H01/bug_0105). Fix: the harness passes
two states per element — none, and a middle child with focus-within and a
preceding-sibling list (`h1.title`, `p`, hovered, with a dataset and a
position) — so the structural pseudo-classes, the sibling combinators and
attribute selectors in sibling compounds are fuzzed too.
