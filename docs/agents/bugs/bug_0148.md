## Root cause and fix
`TestUi::with_layout`/`with_pointer` include picking, whose
`update_pseudo_states` rewrites every element's `PseudoState` from the
hover map each frame: a hand-inserted hover lasted one frame. The sibling
test passed before only because bug_0138 ignored the sibling's `:hover`.
