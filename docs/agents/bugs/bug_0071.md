## Symptoms

Any clicked bound element with a parent form emitted the form's `Submit`
signal. The docs (AGENTS.md) and the code comments already described
submit-button-only gating; only the submit button is supposed to submit
(this is a user-visible behavior change — apps that relied on
any-click-submits must move the hook).

## Root cause

`on_pointer` called `emit_form_submit` for any clicked bound element with
an enclosing form; nothing read the `FormSubmitButton` marker (only
inserted/removed), while the comments at the insertion sites claimed
"`on_pointer` checks the marker".

## Fix

Only a `FormSubmitButton` click submits; the button counts as bound for
`click` in the deepest-bound-element rule, so a bound ancestor's click
doesn't fire for a click on it (a wrapper submits exactly once)
(`cd21ffd`).
