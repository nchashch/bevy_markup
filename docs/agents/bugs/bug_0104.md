## Symptoms and repro
`image_urls` collected every custom `url()` but skipped a slot for schemed/unresolvable ones (a `data:` URL between two file URLs); `Stylesheet::image` paired by position into a separate `images` vector built from the loaded handles — so `var(--b)` could draw `c.png`'s handle. The fuzz harness's `custom_urls`/`handles` construction (temp asset root) built them in reverse order, so it never modeled the loader-level skip. Fixed: replace the parallel-vector structure with a `Vec<(String, Handle<Image>)>` — each URL pairs to its own handle, and a `None` entry has no slot to shift.
