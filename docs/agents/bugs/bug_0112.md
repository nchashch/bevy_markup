## Symptoms and repro
With no `IsDefaultUiCamera`, `max_by_key(|(_, default)| default.is_some())`
over the cameras returned the *last* one (all keys equal): `calc(50% -
20px)` on the root resolved to `Px(30)` against a 100 px minimap camera
instead of `Px(300)`.

## Root cause and fix
A hand-rolled default-camera pick. Fix: `DefaultUiCamera::get()` — the
marked camera, else the window camera Bevy UI renders with — as
`anchor.rs` already did.
