## Symptoms

`update_focus_states` and the exclusive `dispatch_signals` were unordered
against each other (both only ordered against `Render`): a handler that
moves focus restyled it a frame late.

## Fix

`update_focus_states` runs after `dispatch_signals`, so the frame's
handler-driven focus changes show their pseudo-state the same frame
(`cd21ffd`).
