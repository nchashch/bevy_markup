## Symptoms and repro
`.a:not(:hover) { background: red }` left an unhovered `.a` unstyled.

## Root cause and fix
`:not` negated its argument with the argument's pseudo test dropped (a
compound that matches everything). Fix (ADR 0030 §2): the argument is
tested whole against the element's state; for ADR 0029's reactivity record
a wildcarded pseudo is `Tri::Maybe`, which negation keeps, so
`.row:not(:hover) .label` counts as flip-reactive and its flips restyle.
