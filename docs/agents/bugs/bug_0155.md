## Root cause and fix
ADR 0031's commit added `bevy::ui_widgets::UiWidgetsPlugins` to the layout
harness for the `ScrollArea` wheel handling. The group includes
`TextInputPlugin`, which `BevyMarkupPlugin` adds itself under
`text-input`: "plugin was already added". Fix: add only
`ScrollAreaPlugin`.
