# bug_0018 — An app `ImageNode` on a built element turned every restyle into a rebuild (rebuild every frame)

**Status:** fixed (uncommitted at filing). **Severity:** high — a UI that
puts an image on one of its elements (an icon) rebuilds every frame: its
entities never live past one frame and anything not re-attached on
`HtmlUiBuilt` is lost.

**Component:** `src/build.rs` (`same_shape`, `Tree`).

## Symptoms

Found in prototype_19 (playtest 0022 F1, its ADR 0015): the pause menu's
controls tips attach an atlas `ImageNode` to each `<div class="icon">` on
`HtmlUiBuilt`. Every tip entity was replaced within 0.5 s, continuously, and
the app's UI-tree dump never saw the labels (they were always freshly
spawned, not yet laid out).

## Root cause

`same_shape` compared `Has<ImageNode>` on the existing node against
`spec.image.is_some()` — the CSS `border-image` frame. An `ImageNode` the
app inserted looked like a frame the new spec lacks → shape mismatch → the
restyle fell back to a full rebuild. The loop: build → `update_pseudo_states`
inserts `PseudoState` on the new elements → `Changed<PseudoState>` restyles
the UI → mismatch → rebuild → the app re-attaches its images → …

Same class as bug_0017 (app-attached state counted as spec shape), for a
component instead of children.

## Fix

The pipeline marks frames it owns: `spawn_spec`/`apply_spec` insert a
crate-private `CssFrame` with the frame's `ImageNode`, and `Tree` /
`same_shape` compare `Has<CssFrame>` instead of `Has<ImageNode>`. A frame
appearing or disappearing is still a shape change (rebuild); an app image is
app state, kept by restyles like any other attached component. The `html`
rule's frame on the root was already tracked separately (`CssRootBox`).

## Regression test

`tests/html_ui.rs` `restyle_keeps_an_apps_image_on_an_element`: an app
`ImageNode` on a built `<div id="icon">`, then a stylesheet swap that also
resizes it — asserts no `HtmlUiBuilt`, the new width applied and the app's
image kept. Fails with `Tree` reverted to `Has<ImageNode>` (spot-checked:
`restyled, not rebuilt` panics); passes with the fix.
