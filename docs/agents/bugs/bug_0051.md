## Symptoms

`border-image: var(--frame) 16` (or the same via an inline `style`) draws
no frame: the image dependency is missing, so the asset is never loaded.

## Root cause

`image_urls` read only typed `BorderImage`/`BorderImageSource` values; a
`var()` reference resolves later, and the actual `url()` lives in the
sheet's `--frame` declaration's tokens, which were never scanned.

## Fix

`image_urls` also collects `url()` tokens from the sheet's `--`
declarations, so both sides load (`49525d2`).
