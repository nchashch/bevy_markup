## Root cause and fix
The measurement only ever added opaque marks, revisited a container
only when its size changed, and didn't count a mark change as news. A
one-column grid restyled to a flex column keeps its size: it stayed
opaque. Fix: the mark is kept in step both ways, a flip sets
`WindowModel::changed`, and `Changed<Node>` joins the measurement's
filter. `positioned` marks still only grow (bounded over-building: a
subtree that stops holding a positioned element never culls again until
the model clears).
