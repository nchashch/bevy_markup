## Symptoms
`grid-template-columns: repeat(2, [a] 1fr [a])` — the name at the
boundary between merged repeat segments registered twice, so `3 a`
resolved to the FIRST occurrence instead of the third. (Names inside
`auto-fill` repeats never register, so that shape cannot show this.)

## Root cause and fix

The duplicate-registration check ran per registration; a merged
boundary registered the same line for the same name twice, and
occurrence indexes then counted the phantom. `8512b7a` skips a
registration when the name's last entry is the same line — but that
check was quadratic in the name count (review_0003 G28: fixed to
compare only the last pair).
