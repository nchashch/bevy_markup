## Root cause and fix
The inline run walk built positions but no `previous_siblings`, and
`push_runs` computed a root's position from a one-element list. Fix:
`sibling_states` gives every run-walk child its position and its sibling
view; `push_runs` takes the caller's `ElementState`.
