## Symptoms and repro
A regression from bug_0058's own fix (`8e941f7`): `rewrite` never tracked raw-block state through code fences, so a paragraph-level `{% raw %}`/`{% endraw %}` toggle still ran the Tera-literal escaping inside nested code, double-escaping each brace. Fixed by threading `raw` state into the rewrite loop's code-arm handling, matching the paragraph scan.
