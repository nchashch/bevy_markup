## Symptoms and repro
`resolve_calc` wrote each resolved value through `node_field_mut(&mut
node, …)`; taking `&mut` through a `Mut<Node>` marks it changed even for
an equal write, and `ui_layout_system` re-upserts every changed node into
taffy — so layout was dirtied per frame for every element using `calc()`.

## Root cause and fix
Fix: compare through the immutable deref first, write only on a change.
