## Minimal reproduction

`<p>\u{a0}10\u{a0}\u{a0}km\u{3000}x </p>`

- Observed: `10 km x`
- Expected: `\u{a0}10\u{a0}\u{a0}km\u{3000}x` (HTML collapses only ASCII whitespace).

## Root cause

`char::is_whitespace` (Unicode) instead of HTML whitespace.

## Fix

`is_html_whitespace` = `char::is_ascii_whitespace` (space, tab, LF, FF, CR).
