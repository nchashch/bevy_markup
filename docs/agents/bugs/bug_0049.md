## Symptoms

`grid-column: -1 a` against `[a] 1fr [a] 1fr [a] 1fr [b]` resolved line 2
instead of line 3 (the last `a` line); an occurrence past the existing
count (`-3 a`) clamped to the *first* occurrence instead of placing
`auto`.

## Root cause

The negative-occurrence walk started from the wrong boundary index.

## Fix

Negative occurrences count from the end (`-1 a` is the last `a` line),
and running past the occurrences leaves the placement `auto` (`6195a88`).
