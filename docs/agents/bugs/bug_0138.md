## Symptoms and repro
`.a:hover + .b` colored `.b` before any hover; `[data-m="dark"] + p`
matched after `data-m="light"`; `[data-m="dark"] p` matched under any
ancestor; `li:first-child span` never matched (documented limit).

## Root cause and fix
Siblings were matched by tag/ids/classes only, and `Ancestor` carried no
dataset or position. Fix (ADR 0030 §1): one matcher (`Compound::test` over
a `Subject`) for the subject, ancestors and siblings; `Ancestor` carries a
shared dataset and a `Position`, so every part applies in every position.
