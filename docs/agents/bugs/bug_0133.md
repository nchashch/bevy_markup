## Symptoms and repro
`p:nth-child(n-2147483647) { … }` → `attempt to subtract with overflow`
at `cascade.rs:972` while styling.

## Root cause and fix
`AnB::matches` computed `index - b` in i32 with `a`/`b` straight from the
sheet. Fix: the arithmetic runs in i64 (`index` converted with
`try_from`), where no i32 `a`/`b` and no realistic index overflows.
