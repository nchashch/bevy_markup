## Symptoms

`pointer-events: var(--pe)` and `outline-offset: var(--o)` were dropped
as unsupported values, although the docs say `var()` works in "any
property" and lightningcss has no typed form for these.

## Root cause

Substitution ran only on values that had *failed* to parse into a typed
form; properties that parse as raw/unknown tokens were applied without
substituting their `var()` references.

## Fix

Custom-property and raw-token declarations substitute like any other
value (`e992bf1`).
