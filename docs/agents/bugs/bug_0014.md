## Minimal reproduction

```css
html { font-size: 20px }
p { width: 100px; padding: 5px }
```
```html
<p>padded block</p>
```

- Observed: one line, 144px wide, overflowing the 100px content box; block 34px tall.
- Expected (Chromium): wrapped onto two lines inside the content box; block 58px tall.

`width` alone wrapped correctly; any box property (padding, border,
background, border-image) broke wrapping.

## Root cause

A block with box properties is spawned as a wrapper node holding the `Text`
node. The wrapper was a default `Node` — a flex *row* — and the text node has
`flex_shrink: 0`, so it kept its max-content width instead of the wrapper's
content width.

## Fix

The wrapper is a flex column: the text stretches to the content box and
wraps there, like a CSS block.
