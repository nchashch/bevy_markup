## Symptoms and repro
`md::to_html_template("<div class=\"card\">\n\n    Some **text**\n\n</div>\n")`
rendered `<pre><code>Some **text**</code></pre>` inside the div.

## Root cause and fix
CommonMark ends an HTML block at a blank line, and a 4-space line after a
blank line is an indented code block; bug_0126's dedent only knew Tera
blocks. Fix (ADR 0025): an own-line opening tag (not void, not
self-closing, the only tag on its line) and its own-line closer form a
block in `dedent_blocks`, nested with Tera blocks on one stack; `<pre>`,
`<textarea>`, `<script>` and `<style>` bodies stay verbatim.
