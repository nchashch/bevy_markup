## Root cause and fix
A culled subtree whose content changed kept its last measured height in
the model; culling it by that height put a wrong spacer in its place, so
the layout moved everything after it. Fix: `Ctx::cull` culls only a
subtree that is clean in this build's pairing. A changed one builds for
one frame and is measured; the measurement's rebuild culls it again.
