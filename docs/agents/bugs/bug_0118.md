## Symptoms and repro
Includes, Fluent resources, `border-image` URLs and 9-slice images
accepted `https://…`: with Bevy's web asset sources enabled, a mod's or
user's template fetched remote files. `<img>` already refused `://`.

## Root cause and fix
No source check besides `is_unapproved`. Fix: `is_remote` rejects Bevy's
network sources (`http`, `https`; other sources such as `embedded://`
or an app's own stay usable): includes, resources and slice images fail
their load; a remote border-image is skipped with a warning, like a
custom property's schemed URL.
