## Symptoms

A restyle that respawns text spans (run merge/split under a new sheet —
e.g. a theme swap changing which runs exist) fired only
`HtmlUiRestyled`, although the new link spans were fresh entities: app
wiring attached to the old spans was gone while the event promised every
element was kept.

## Root cause

`update_spec`'s restyle path didn't report when it respawned spans, and
AGENTS.md (and ADR 0009's model) promise `HtmlUiBuilt` "after a content
update (or a restyle that spawned nodes)".

## Fix

A span respawn during a restyle is reported as a build: `HtmlUiBuilt`
fires instead of `HtmlUiRestyled` (`c07dda7`).
