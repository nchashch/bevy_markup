## Symptoms

A message whose pattern has no placeables skipped the cache
(`&& index > 0` in the cache fill) and was Markdown-converted on every
`localize` — every frame for a per-frame context — although ADR 0020's
contract is one conversion per bundle load.

## Fix

Placeable-free messages are cached too (`402362c`).
