## Symptoms and repro
`eprintln!("DBG count arm text={text:?} raw_before={raw}")` (`bde26f8`,
G07) ran for every Markdown text/HTML event containing raw tags;
`eprintln!("G13 DBG indented line taken: …")` (`2e14ba8`) for every
4-space-indented line of every `.md` template at load. Test-only:
`tmp_probe` and `throwaway_columns_decl` (no assertions), `G14 DBG`
prints, `AREAS:`.

## Root cause and fix
Debugging output committed with the fixes. Removed; the assertion-less
tests deleted (`THROWAWAY-TO-KEEP: combinator matching` became the
`selector` helper's doc); the G14 prints became assertions (bug_0094).
