## Symptoms

`p { --a: var(--brand); color: var(--a) }`: changing the context's
`--brand` never restyled the UI — the color stayed. Same for a variable
referenced from an inline `style` attribute.

## Root cause

`var_names` returned only the names literally referenced in typed
properties; the transitive path (`--a` → `--brand`) was not followed, so
the `vars_changed` hash didn't change when `--brand` did. (Inline `style`
attribute values are not part of the hash at all — still open.)

## Fix

`var_names` follows references through the sheet's own `--` declarations
to a fixpoint, and is computed once at load and stored on `Stylesheet`
(instead of rescanning the whole sheet every frame for every UI)
(`6195a88`).
