## Root cause and fix
`%` margins resolve against the parent's content width, looked up
through a query that requires `ChildOf`. A top-level element's parent is
the `HtmlUi` root, which has none: the lookup failed, the basis was 0,
and the margins counted as 0 in the spacer. Fix: the width comes from a
plain `ComputedNode` query.
