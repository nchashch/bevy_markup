## Root cause and fix
ADR 0031's implementation (`ec085b1`) unwrapped a single walked-through
root (`html`, then `body`) so the window's cursor started at the content,
and collected the unwrapped children with the root's style and an empty
ancestor chain. It ran for every UI. The wrappers' own declarations and
every selector naming them were lost. Fix: no unwrap. The roots are
collected as before ADR 0031, and the window passes its cursor through
walked-through elements instead (bug_0175).
