## Symptoms

`<input type="checkbox">`, `<input type="password">` or any other
non-text `type` rendered an editable text field. ADR 0016 says the other
types stay unsupported.

## Root cause

The field's eligibility read `type` from the element's `dataset`, i.e.
the `data-type` attribute; the real `type` attribute was never consulted,
so every `<input>` (whatever its `type`) became a field.

## Fix

The field is built from the real `type` attribute; only a text (or
missing) `type` builds it. Other types are dropped like any unsupported
empty inline leaf — no field, no element (`bbd0959`).
