## Minimal reproduction

`pre { border-width: 3px; border-style: solid; padding: 1px }`

- Observed: Wrapper padding 1px plus the inner text node's fixed 8px.
- Expected: 1px total: CSS padding replaces p23's default per side, as an author rule overrides a UA rule.

## Root cause

The default 8px always sat on the inner text node; box properties went on the wrapper.

## Fix

The padding is `rect_over(8px default, css)` on whichever node holds the box.
