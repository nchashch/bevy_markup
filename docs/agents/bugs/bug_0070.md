## Symptoms

A `*.slice.ron` manifest with `Tile(0.0)` divided by zero (infinite
repeats in Bevy's slicer); negative insets and NaN/≤0 `max_corner_scale`
were accepted and drew garbage, with no load error.

## Fix

Manifests validate: insets ≥ 0, tile factors and `max_corner_scale`
finite and > 0; invalid values fail the load (`402362c`).
