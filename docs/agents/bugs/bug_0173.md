## Root cause and fix
The build clears the model when the root's content width differs from
the model's anchor. But the measurement, which runs after the resize's
layout and before the next build, set the anchor to the new width. The
check never fired, and the culled rows kept heights measured at the old
width. Fix: the measurement clears the model itself when the width moved
(every built entity is re-measured at once) and flags a rebuild.
