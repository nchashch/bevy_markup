## Symptoms

`a { color: #4af } .nav a { color: inherit }` kept nav links at `#4af`;
`width: initial` kept the earlier 200px. The keywords fell into the
unsupported `_ => {}` arm, so the *lower*-priority rule's value won.

## Fix

`initial`, `inherit`, `unset` and `revert` return the field to its
initial value; `inherit` resolves to the initial value too — the cascade
keeps no parent computed style (documented deviation) (`e992bf1`).
