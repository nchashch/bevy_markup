## Symptoms

`repeat(2, [a] 1fr [b]) [c]`: `b` is unresolvable (the name at the end of
each repetition was dropped). `[full-start] repeat(auto-fill, 100px)
[full-end]`: the names *around* the repeat were dropped too, although the
docs only exclude names *inside* such a repeat.

## Root cause

The repeat expansion registered `[name]` pairs strictly between tracks
(`if j < tracks`), losing the repetition's end boundary, and the
auto-fill branch discarded the whole list's names.

## Fix

A name at the end of a `repeat()` registers (the end boundary merges with
the next repetition's start); names around an `auto-fill`/`auto-fit`
repeat keep their knowable spellings — before the repeat as positive
lines, the final boundary from the end (`6195a88`).
