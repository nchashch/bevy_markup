## Root cause and fix
bug_0161's refusal builds a changed subtree to measure it. When its
height didn't change, the measurement had no news and nothing rebuilt,
so the subtree stayed built outside the band. Fix: a refused cull flags
the band stale (`WindowCtx::stale`), and the build sets
`WindowModel::changed` from it: the next frame rebuilds once and culls
it.
