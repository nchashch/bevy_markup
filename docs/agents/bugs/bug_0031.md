## Symptoms

A `TemplateContext` change dropped unchanged elements that sit next to the
changing one, when the changing subtree's root tag produces no node of its
own: `<div><p>{{ n }}</p><span>static span</span></div>` with `n` changed
lost the span. Same for an `<img>` in a container, and for `<body>` when
`<head>` carried the change.

## Root cause

`collect_node` returned after `skeleton.reuse` even when `reuse` found
nothing for that node (the comment claimed it "falls through"). A
walk-through tag (`span`, `b`, `<img>` in a container) produces no spec of
its own, so the failed lookup short-circuited the fresh collect of its
children.

## Fix

`reuse` returns `false` when nothing was reused and the caller collects
normally (`0ede9b6`).
