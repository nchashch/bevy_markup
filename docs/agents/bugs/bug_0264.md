## Symptoms

Five small CSS spec-conformance defects in the ADR 0048 parser and cascade:

1. **Multi-layer `background` discards the final layer's `background-color`:** `#a { background: url('frame.png'), #ff0000; }` resolves to `bg=#00000000 bg-image=frame.png` instead of taking `#ff0000` from the final layer (CSS Backgrounds 3).
2. **`background: initial` (and `background-image` / `background-repeat` / `background-clip: initial`) are no-ops:** `.red { background: #ff0000; } .clear { background: initial; }` keeps `bg=#ff0000` (control: `background-color: initial` clears it).
3. **Non-rectangular `grid-template-areas` accepted:** `grid-template-areas: 'a b a';` is accepted instead of rejected (as CSS Grid 1 requires and `lightningcss` previously did), placing `#a` at `GridPlacement { start: 1, end: 4 }` overlapping `#b` at `2..3`.
4. **`repeat(0, ...)` accepted in grid track lists:** `grid-template-columns: repeat(0, 1fr);` parses as valid (CSS Grid 1 requires `<positive-integer> >= 1`) and reaches Bevy `Node` as `RepeatedGridTrack { repetition: Count(0), .. }`.
5. **`transition` accepts empty comma-separated items:** `transition: color 1s, ;` parses as valid with a trailing `("all", 0.0, 0.0, Ease)` entry instead of being rejected.

## Root cause

1. `background` (`src/css/property.rs:1596–1605`) takes `(color, image)` from `layers[0]` and overwrites `color` with transparent `(0, 0, 0, 0)` whenever `layers.len() > 1`, ignoring the final layer's color (and allowing colors on non-final layers).
2. `apply_keyword` (`src/cascade.rs:2097–2261`) handles `"background-color"` but omits `"background"`, `"background-image"`, `"background-repeat"`, and `"background-clip"`.
3. `parse_areas` (`src/cascade.rs:2991–3031`) computes only each area's min/max bounding box without checking that every cell inside `[r1..=r2] × [c1..=c2]` belongs to that area.
4. `track_repeat` (`src/css/grid.rs:218–231`) accepts `0` from `parse_integer`, and `src/cascade.rs:2850` forwards it to `GridTrackRepetition::Count(0)`.
5. `transition` (`src/css/property.rs:1850–1899`) exits its per-entry loop immediately on an empty item and returns `Ok(("all", 0.0, 0.0, Easing::Ease))` without checking that at least one component value was consumed.

## Fix

- Updated `background` / `background_layer` (`src/css/property.rs`) to reject colors on non-final layers and take `background-color` from the final layer.
- Added `"background"`, `"background-image"`, `"background-repeat"`, and `"background-clip"` to `apply_keyword` (`src/cascade.rs`).
- Added O(N) `areas_are_rectangular` validation in `src/css/grid.rs`, called by both `template_areas` and `template`.
- Rejected `n <= 0` in `track_repeat` (`src/css/grid.rs`).
- Required each `transition` comma-separated item to consume at least one token (`src/css/property.rs`).
- Both unit and rectangularity property tests failed before the fix and pass with it.
