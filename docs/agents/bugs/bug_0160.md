## Root cause and fix
The skeleton paired raw text nodes for reuse but didn't record them in
`pairing`/`reverse`/`clean`. A raw text node keys its anonymous block's
height (ADR 0031), so the content build's remap dropped every loose
text's height: the cursor met an unknown height and stopped culling in
that frame. Fix: the raw arm records the pair like an element, and an
unchanged text is clean (its stored height still holds).
