## Symptoms

After `a,b` → theme switch to an unloaded sheet plus `b,a` → `a,c`, the UI
shows `"b","c"`; a fresh build shows `"a","c"`. The debug outline
switching off reproduces it too — the document the skeleton pairs against
is older than the specs it serves.

## Root cause

The skeleton's stored document was re-parsed only when
`rendered.is_changed()` in the frame that also ran the build. A render
that changed during a `Wait` frame (a sheet loading) or an outline frame
left the stored document behind; the next reuse paired new content against
the old document's shape.

## Fix

The current document source is tracked across the held frames and the
skeleton's document is re-parsed from it when the build finally runs
(`0ede9b6`).
