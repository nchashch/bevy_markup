## Symptoms and repro
`"&#1".repeat(40_000)` decoded ~15× slower than `repeat(10_000)`.

## Root cause and fix
`terminated_digits` split the rest of the text at the next `;` before
checking the digit bound, so each `&#` scanned to the end. Fix: it reads at
most `max + 1` bytes of digits of the radix and then requires the `;` —
which also stops a sign from counting as a digit (bug_0146).
