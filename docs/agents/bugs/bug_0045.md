## Symptoms

`:focus-visible { … }` — the standard focus-ring rule — never applied,
and neither did `*:focus`: rules whose compound has no type, class or id
were dropped entirely.

## Root cause

lightningcss prints `*:hover` back as `:hover`, and `Compound::parse`
rejected a compound with no simple-selector part of its own, dropping the
whole rule.

## Fix

A pseudo-only compound matches any element (`e992bf1`).
