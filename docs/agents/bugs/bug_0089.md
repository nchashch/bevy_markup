## Symptoms and repro
`RUSTFLAGS=-D warnings cargo build --all-targets` exited 101 (unused
imports `ScheduleRunnerPlugin`/`UnapprovedPathMode` in nine_slice.rs's
test, an unused `json` in l10n.rs, unused bindings in tests). GitHub stops
at the first failing step, so no test ran in CI. Separately, two new tests
had been inserted between an existing test's doc comment + `#[test]` and
its `fn`: `unapproved_paths_fail_their_loads` and
`enter_and_leave_track_the_hovered_subtree` became plain (dead)
functions while their neighbours carried two `#[test]`s.

## Root cause and fix
Insertions that split an item from its attributes (`363991f`, `15b4255`,
`700d047`, `37250f6`, `1e3d37a`, `3d23a81`, `04d730d`), and claiming green
without running CI's commands. Fix: removed the unused items, reattached
the attributes and doc comments; the loader test polls its load state
instead of a fixed frame count (R47's flake).
