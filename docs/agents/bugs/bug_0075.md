## Symptoms

`#a #b #c` (no autofocus, entities recycled from a previous UI) focused
`#c` — the lowest `Entity` sorts by generation/index, i.e. recycled
order. Same for the modal-open and focus-lost fallbacks.

## Root cause

The fallback took `.min()` over a query keyed by `Entity`.

## Fix

`first_focusable_in_scope`: a depth-first walk of each in-scope root's
subtree (the same order the build spawns/updates in) (`cd21ffd`).
