## Symptoms and repro
`format!("p {{ {} }}", "a {".repeat(n))` through the loader's pre-scan
and `StyleSheet::parse` on a 2 MiB thread: n = 500 aborts in a debug
build (n = 300 parses), n = 1000 (3 KB) in release — `thread 'IO Task
Pool' has overflowed its stack … SIGABRT`.

## Root cause and fix
`nesting_over_limit` (bug_0092's pre-scan) counted only `(`; CSS nesting
recurses per `{`. Counting more brackets with the old saturating counter
would still undercount: a `)` inside a string (`( ")" ( ")" …`), a
comment, an escape, an unquoted `url(…)`, or a mismatched closer kept
the count at zero while the parser's nesting grew — a bypass the
parens-only scan already had. Fix: the scan mirrors cssparser's block
matching — a stack of open `(`/`[`/`{`, a closer pops only its own kind,
strings/comments/escapes/unquoted URLs are skipped — and rejects past
`MAX_CSS_NESTING` (32). Where unsure it counts (overcounting only rejects).
