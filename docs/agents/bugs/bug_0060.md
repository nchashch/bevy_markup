## Symptoms

An `.html` partial included from a `.md` page: its indented HTML was
treated as an indented code block and wrapped in
`<pre class="markdown">`. A `.md` partial included from an `.html` page
stayed raw Markdown text.

## Root cause

The loader picked the conversion mode from the *root* template's path
(`is_markdown(&name)`) and applied it to every file it read.

## Fix

Each included file is converted by its own path
(`is_markdown(&path.to_string())` per file) (`402362c`).
