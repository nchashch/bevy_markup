## Symptoms and repro
`<div data-on-click="wrap"><form data-on-submit=""><button>Go</button></form></div>`:
clicking Go emitted nothing — no submit (the empty name binds nothing)
and no `wrap` click.

## Root cause and fix
The build marked submit buttons for any form with a `data-on-submit`
attribute (`is_some()`), while `signal_bindings` skips blank names; the
marked button counted as bound and swallowed the wrapper's click. Fix:
`form_submits` requires a non-blank name, at both chain sites.
