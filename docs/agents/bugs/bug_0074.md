## Symptoms

Hovering `<a href data-tooltip>`: the tooltip is added and despawned
every frame (31 `Add<HtmlTooltip>` per 30 hovered frames, 0 alive) —
never visible.

## Root cause

The hover hit is the link span, which carries `HtmlElement` + tooltip
data but no `ComputedNode`/`UiGlobalTransform`; `place_anchored` treats an
anchor element without a node as gone and despawns.

## Fix

The tooltip anchors to the nearest ancestor that has a node; the
anchor's element is rewritten when that target changes (`cd21ffd`).
