## Root cause and fix
The skeleton doesn't pair a container whose child count changed
(bug_0168), so the content build's remap drops its subtree's heights. A
kept entity whose handle didn't shift and whose size didn't change
matches none of the measurement's `Changed` filters: its height stayed
unknown for good. Fix: a remap that drops heights sets `remeasure`.
