## Symptoms and repro
`md::to_html_template("{% if a %}\n    Some *text*\n{% endif %}\n")` →
`{% if a %}\n<pre class="markdown"><code>Some *text*\n</code></pre>\n{% endif %}`.
An indented `{% for %}`/`{% if %}` body (the usual Tera habit) rendered as
a code block, with its Markdown shown literally.

## Root cause and fix
`separate_statements` gives an own-line statement a blank line after it
(ADR 0020), and CommonMark reads a 4-space line after a blank line as
indented code. Fix (ADR 0024): before separation, `dedent_blocks` removes
from each own-line block body (per `elif`/`else` segment, recursively,
capped at 16 levels) the indentation its lines share. Statement lines that
pulldown reads as code are content; `raw` bodies dedent but aren't
searched; offsets map back for the include scanner.
