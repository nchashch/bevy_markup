## Root cause and fix
The measurement visits only entities whose key was added or changed, or
whose `ComputedNode` changed. After `WindowModel::clear` (a width change)
a kept entity whose layout held was never visited again: its height
stayed unknown and its frame never culled. Fix: `clear` sets
`remeasure`, and the next measurement visits every keyed entity of the
UI.
