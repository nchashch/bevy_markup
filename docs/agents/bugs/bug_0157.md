## Root cause and fix
The offset was compared exactly with the last build's. Fix: every cull
decision records how far the offset may move before it flips (a culled
element flips only past its distance; a materialized one at it, so its
slack is shortened by an epsilon); a subtree reused whole counts by its
own top and bottom. The model keeps the anchor and the slack
(`WindowModel::anchor`/`slack`); the UI rebuilds when the offset leaves
the slack. The trigger also compares the viewport's height — before, only
its width was watched, so a taller root kept its old band.
