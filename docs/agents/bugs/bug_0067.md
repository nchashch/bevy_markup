## Symptoms

A `{% include "gone.html" %}` inside a `{# … #}` comment, inside a
`{% raw %}` block, or inside a Markdown code sample was still resolved
(and loaded): a commented-out include of a deleted file failed the whole
template load, leaving the UI blank.

## Root cause

`resolve_references` scanned for `{%` tags over the raw source without
any context.

## Fix

The scan skips `{# comments #}`, `{% raw %}` blocks and (in `.md` files)
fenced code blocks and inline code spans; the earliest of tag/comment/raw/
code-start wins (`402362c`).
