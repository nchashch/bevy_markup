## Symptoms and repro
`md::to_html("\u{1}bevy-markup\u{1}<b data-x=' class=\"é'>x</b>")`
panicked at the class-append slice: `MARKER` is plain U+0001-delimited
text that content can supply, and a `class="` run inside another
attribute's value without a closing quote sliced past the end or inside a
multi-byte character.

## Root cause and fix
`value_end` fell back to `value_at` (`unwrap_or(0)`) with no closing
quote, then sliced at `value_end + 1`. Fix: without a closing quote the
tag is emitted verbatim and the marker dropped, like the function's other
bail-outs. (A class-like run inside another attribute's value *with* a
closing quote still gets the class appended inside that value —
cosmetic; it can't leave the tag.)
