## Symptoms

Any `background-image` with `background-repeat` tiling an axis (the
default) drew a **solid fill of the image's rim color** — none of the
tile's interior appeared, at any block size.

## Root cause

The `ImageNode`'s `NodeImageMode::Tiled` got `stretch_value: 0.0`.
Bevy's tiled rendering computes the tile scale as
`target_extent / (image_extent * stretch_value)`
(`bevy_ui_render::compute_tiled_axis`), so 0.0 is a division by zero;
the resulting degenerate geometry rendered the rim as a solid fill.
Tiles at the image's intrinsic size need `stretch_value: 1.0`.

## Discovery path

The new golden scene's first recorded reference looked wrong (no black
center anywhere); the browser oracle can't catch drawing, and
`background-size` is unsupported, so no dump field pins it either — the
golden image was the only surface that could.
