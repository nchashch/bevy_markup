## Symptoms and repro
A 40 px `overflow-y: auto` panel with six paragraphs: `overflow.y` was
`Scroll` after the first build and `Hidden` after a class change or a
`:hover` that restyled it in place.

## Root cause and fix
The promotion ran only on `Changed<ComputedNode>`; an in-place update
rewrites the `Node` (axis `Hidden`) without changing the layout. Fix: the
query runs on `Changed<ComputedNode>`, `Changed<Node>` or
`Changed<AutoScroll>`, and writes the axis only when it differs (a plain
`&mut` marked the `Node` changed on every run).
