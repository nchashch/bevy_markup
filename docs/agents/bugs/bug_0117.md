## Symptoms and repro
`--a: var(--b, 1px); --b: var(--a, 2px); width: var(--a, 7px)` →
`Px(1)`; CSS says `Px(7)`: both `--a` and `--b` are on the cycle, so both
are invalid at computed-value time whatever their fallbacks, and the
width's own fallback applies.

## Root cause and fix
A `cycle` flag skipped the fallback only at the reference that closed the
cycle (`--b`'s `var(--a, …)`); `--a`'s own `var(--b, 1px)` then took its
fallback. Fix: the resolution chain is an ordered stack; re-entering a
name marks every name from it to the top as cyclic; a cyclic name is
invalid, and inside one nothing takes a fallback. A reference from
outside the cycle still takes its own.
