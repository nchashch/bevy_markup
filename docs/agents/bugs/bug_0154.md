## Root cause and fix
The first build has no heights and builds everything; the measurement
then fills the model, but nothing triggered another build — only a scroll
or a width change did. Fix: `WindowModel::changed`, set when the
measurement learns a new height or one that moved by more than 0.5 px,
triggers one rebuild and is consumed by it (heights converge, so it
settles).

With the rebuild, a root that isn't laid out (zero height: before the
first layout, or a render-less app such as the testbench's `--no-render`)
got a zero-height band and culled the whole document into one spacer. An
unknown viewport now windows nothing (`an_unlaid_windowed_ui_builds_everything`,
fails without the guard).
