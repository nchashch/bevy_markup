## Symptoms and repro
`cargo check --lib --features fuzzing` failed: `HtmlStyles::from_sheet`
took two arguments since `1de2033`, and the harness (compiled only under
the feature) still called it with one.

## Root cause and fix
An API change didn't run the feature-gated check AGENTS.md's gotcha asks
for. Fix: pass the harness stylesheet's `var_names`. The same class
recurred with `944e8fa`'s `Ancestor` change (bug_0105), which is why CI
now checks the feature right after the plain library checks.
