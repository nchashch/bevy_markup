## Symptoms

A `markdown: true` message containing a term or message reference
(`{ -brand }`) rendered the reference as escaped literal text
(`&lt;b&gt;…`), while the same message through the per-value path
resolved the reference. ADR 0020 Decision 4 calls only *arguments*
literal.

## Root cause

The cache substituted formatted values into a pattern converted at load;
term/message references need Fluent's resolution machinery, which the
cached text no longer has.

## Fix

Messages containing term/message references don't use the cache — they
convert per value, like the other uncacheable shapes (`402362c`).
