## Symptoms

`[docs]({ $url })` through a `markdown: true` bundle produced literal
text with no link; the per-value path produced the `<a>`.

## Root cause

The cache converts the pattern with placeables replaced by `\u{2}`/`\u{3}`
markers, and CommonMark rejects control characters in link destinations —
the destination stopped being one.

## Fix

Messages whose conversion leaves a marker in a Markdown link destination
don't cache — they convert per value (`402362c`).
