## Symptoms

`<div class="grid"><input type="text" style="grid-row: mid"></div>`
ignored the named row: the input placed `auto` while any other element
with the same style placed by name.

## Root cause

The normal path resolves named lines/areas into the outer box
(`resolve_names(grid)`) before building the spec, but the text-input
branch rebuilt `boxed` from the unresolved box.

## Fix

The text-input branch styles from the outer box (which had
`resolve_names` applied) (`bbd0959`).
