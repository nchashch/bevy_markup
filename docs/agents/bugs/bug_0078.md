## Symptoms

With `UiScale(2.0)`, a plate anchored to a world point lands at twice the
projected position (window-logical px written into `Val::Px`, which Bevy
multiplies by scale × UiScale; `place_anchored` handles this via the
inverse scale factor, the world anchor didn't). With an offset viewport,
the on-screen test compared against `0..logical_viewport_size` while
`world_to_viewport` includes the viewport's origin — every visible point
read off-screen and the plate hid.

## Fix

The projection result is divided by the `UiScale` factor and compared
relative to the viewport's origin (`cd21ffd`).
