## Symptoms and repro
A `.ftl.ron` listing a resource twice re-read and re-parsed it (and
warned about every message as a duplicate); `CustomElements.warned`
grew by one entry per distinct undefined `is=` name for the app's
lifetime; `context_vars_hash` built a `String` per tracked name, per UI,
per frame.

## Root cause and fix
Fix: the loader reads each resolved path once; the warned set stops at
256 names (one final notice); the hash feeds each value's CSS-relevant
form to the hasher directly (`hash_css_value`, no allocation).
