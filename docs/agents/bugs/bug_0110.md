## Symptoms and repro
Layout harness, 400×300 viewport, root `width: Px(400)`: an inline
`width: calc(50% - 10px)` on a root-level `<div>` left `Node.width =
Auto` (laid out at 400); the same on a `<p>` inside a `<div>` gave
`Px(190)`. The calc example worked only because its calc elements sit in a
container.

## Root cause and fix
`resolve_calc` required both the parent's box and the parent's own
parent (for the viewport walk); a top-level root has no `ChildOf`, so its
children hit `continue` every frame — since calc support landed
(`f086b11`). Fix: the parent's box is required; the walk to the top
starts at the parent itself.
