## Symptoms

Every UI without an explicit root `font-size` queued a restyle on its
first build and fired a spurious `HtmlUiRestyled`: Bevy's default
`RemSize` is 20 px, the CSS default 16 px, so the sync always changed the
resource.

## Root cause

The sync queued a restyle "so its `Val::Rem`s re-convert against the new
value" — but that's not how the values re-resolve: Bevy's layout
re-resolves every `Val::Rem` itself when the resource changes. The queued
restyle was pure overhead.

## Fix

`queue_restyle` is removed; the sync inserts the resource only. AGENTS.md
("a change queues a restyle") and ADR 0017's mention remain to be updated
by the docs owner.
