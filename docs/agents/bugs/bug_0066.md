## Symptoms

`A { $x } B { $y } C` with `x = "1 B 2"`: the first-`find`/`replace`
search (front to back, then back to front) matched inside the *value*
rather than the following marker, misassigning the arguments.

## Fix

The substitute walk verifies the whole split (each gap replaces its exact
marker verbatim, the parts anchor start/end); a text that doesn't split
cleanly returns `None` and the caller falls back to the per-value
conversion (`402362c`).
