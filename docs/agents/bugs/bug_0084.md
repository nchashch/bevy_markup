## Symptoms
`markdown: true` bundles cached a resource's converted messages at load; one message with a syntax error (Junk) made the whole resource fall back to per-frame conversion, so a static document re-converted every frame.

## Repro
A bundle with `markdown: true` whose resource has one message with a
syntax error (`!!! junk line` before the good messages): every good
message converted per frame instead of once at load.

## Root cause and fix

`markdown_cache` skipped the WHOLE resource when any message was Junk;
`73ae77f` keeps the resource's good messages (and, for duplicate ids,
keeps the first — the bundle's choice).
