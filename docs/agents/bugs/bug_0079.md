## Symptoms

An app that adds `DirectionalNavigationPlugin` itself after
`BevyMarkupPlugin` — Bevy's documented pattern — panics with "plugin was
already added" (the crate auto-adds it in `build`, undocumented).

## Fix

The auto-add moved to the plugin's `finish`, after every app `build`: an
app adding the plugin itself is detected as intentional, and the
duplicate-add error can no longer hit a plain `build`-order app
(`cd21ffd`).
