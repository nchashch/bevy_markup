## Root cause and fix
A scroll build has an unchanged document; the skeleton paired only on a
render change or a restyle, so it never paired. Fix: a windowed UI's
builds pair too, and four guards make reuse correct and stable:
- a cached subtree reuses only if it holds no spacer and lies wholly
  inside the band (it carries the culling of the band it was built
  under — a container reused whole kept stale spacers, or everything);
- an unchanged document keeps the height model's keys (remapping
  through the pairing, element pairs only, dropped the anonymous blocks'
  heights and stopped the cursor);
- scroll builds keep the adaptive strike state (a long jump reuses
  nothing, and striking for it turned the pairing off for the next
  scrolls);
- `last_reuse` records them.

The testbench's 10 000-row windowed sweep reuses 77 of 79 specs per scroll
build.
