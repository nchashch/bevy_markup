## Symptoms
Before the fix, the comparison was `type == "text"` exactly: a
`type="TEXT"` field built **no** editable field at all (HTML's
matching is ASCII case-insensitive). This regressed from `bbd0959`
(R08's fix, which introduced the comparison). The non-text `type`
half (checkbox/submit building fields) is bug_0067 (R44); the
`type="Submit"` submit half has no test.
