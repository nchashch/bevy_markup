## Minimal reproduction

Default `a.css` (red); insert `HtmlStylesheet(b.css)` (green), settle; `remove::<HtmlStylesheet>()`.

- Observed: Text stays green forever (no rebuild).
- Expected: Rebuild with the default stylesheet (red).

## Root cause

Component removal is not a `Ref` change and `RemovedComponents<HtmlStylesheet>` wasn't read (same class as bug_0003).

## Fix

Removed outlines and removed sheets feed one `removed` set that marks the entity dirty.
