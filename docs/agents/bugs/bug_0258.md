## Symptoms

A short template creates one moderate string `s` and lazily repeats `[s] * N` (costing $O(N)$ item fuel, not $N \times |s|$ byte fuel), then serializes it through a filter or operator and pipes into `| length` so `BoundedOutput` never sees the string. Even when the render eventually fails out of fuel, the entire multi-hundred-megabyte `String` is allocated first.

Measured with `template::new_environment(fuel)` and a counting global allocator (from [review_0010](../reviews/review_0010.md) addendum; `s = 'x' * 100000`, `s' = 'x' * 50000`):

| Fuel | Template | Result | Peak heap | Time |
|---|---|---|---:|---:|
| default (`2²²`) | `([s] * 3000) \| join \| length` | out of fuel | **0.2 MB** | 0.75 ms |
| default (`2²²`) | `([s] * 3000) \| json \| length` | out of fuel | **709.7 MB** | 3.3 s |
| default (`2²²`) | `([s] * 3000) \| tojson \| length` | out of fuel | **709.7 MB** | 335.6 ms |
| default (`2²²`) | `([s] * 1200) \| json \| length` | `Ok(120003601)` | 324.9 MB | 1.4 s |
| default (`2²²`) | `([s] * 300) \| e \| length` | `Ok(30004200)` | 102.5 MB | 337.8 ms |
| default (`2²²`) | `('%(a)65535d' * 500) \| format(a=1) \| length` | `Ok(32767500)` | 66.3 MB | 4.0 ms |
| `10,000` (~640 KB) | `([s'] * 600) \| json \| length` | out of fuel | 81.3 MB | 328.7 ms |
| `10,000` (~640 KB) | `([s'] * 600) \| tojson \| length` | out of fuel | 81.3 MB | 33.6 ms |
| `10,000` (~640 KB) | `([s'] * 600) \| string \| length` | out of fuel | 51.3 MB | 254.0 ms |
| `10,000` (~640 KB) | `[[s] * 300] \| join \| length` | out of fuel | 51.3 MB | — |

At `fuel = 10_000`, `pprint`, `~ ''`, `'%s' | format(...)`, and `safe` all likewise allocated tens of megabytes before failing fuel. Raising `3000` toward `100_000` (still far below `MAX_RENDERED_BYTES / 3 ≈ 5.6M` items) scales peak allocation into tens of gigabytes and OOM-aborts the process.

## Root cause

Four gaps compound:

1. **String bytes inside containers are uncounted before allocating.** Both `fits_printed` (`src/template.rs:293–330`) and MiniJinja's `deep_item_count` count only container item slots (and `tojson` indent bytes after bug_0256), never the byte lengths of strings held inside lists or maps.
2. **Serialized-byte fuel is missing or post-hoc across filters.** `new_environment` (`src/template.rs:228–229`) overrides MiniJinja's fueled `tojson`/`pprint` with `checked_tojson`/`checked_pprint`, calling public unfueled `minijinja::filters::{tojson, pprint}`. `json_filter` (`:755–763`), `checked_format` (`:465–479`, which also allows repeated `%65535d` specifiers and container arguments), and `safe` do not budget serialized bytes up front. `fueled_escape` (`:443–460`) skips charging and `check_printable` whenever `value.as_str()` is `None`, letting containers pass straight to `minijinja::filters::escape`.
3. **Nested non-string items in `join` are undercharged.** `fueled_join` (`src/template.rs:389`) charges non-string items a flat `ITEM_BYTES` (48 B), and MiniJinja's built-in `join` stringifies an inner list without pre-charging its bytes.
4. **MiniJinja's `string` and `~` charge post-hoc (`UPSTREAM U65`).** `State::charge_serialized` charges bytes only after the serialized `String` has already been allocated.

## Fix (proposed)

- Update `fits_printed` / `check_printable` (and MiniJinja's `deep_item_count` / pre-serialization checks) to budget **estimated output bytes**—counting string byte lengths (with quoting/escaping expansion factors) plus per-item and indent overhead—capped by **both** `MAX_RENDERED_BYTES` and remaining fuel (`state.fuel_levels()`), aborting before allocating.
- Pre-charge serialized bytes in `json_filter`, `checked_tojson`, `checked_pprint`, `checked_format` (summed specifier widths + container arguments), `fueled_escape` (non-string values included), `safe`, and `fueled_join` (recursively estimating non-string items instead of flat `ITEM_BYTES`).
- Address MiniJinja's post-hoc `charge_serialized` in `string`, `~`, and `join` on the fork and report upstream (U65).
- Add regression tests asserting both out-of-fuel refusal and low peak heap allocation for `([s] * 3000) | json/tojson/pprint/string/safe/escape`, `[[s] * 300] | join`, `~ ''`, and repeated-width `format`.
