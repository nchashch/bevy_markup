## Symptoms and repro
`<form data-on-submit="send"><button type="sbumit">` never submitted.

## Root cause and fix
`type` had to equal `submit`; HTML's missing *and* invalid value default
is `submit`. Fix: every value but `button`/`reset` (ASCII
case-insensitive) submits.
