## Symptoms and repro
400 px viewport, root `width: Px(100)`, `<div><p style="width: calc(50vw
- 10px)">`: 40 px (correct: 190), while a plain `50vw` (Bevy's `Vw`) was
200 px.

## Root cause and fix
The viewport of a nested element was the top-level root's box ("a UI
root measures the window" — true only for full-window roots). Fix: one
`viewport_of(top)` for roots and nested elements alike — the camera the
top root targets, else the default UI camera, else (no camera) the
root's box.
