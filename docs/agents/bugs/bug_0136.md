## Symptoms and repro
`.hot + p { background: red }`; change the preceding div's class from
`hot` to `cold`: the reused `p` stayed red while a fresh build had none.
Same for `~`, `:nth-of-type`, `:last-of-type`.

## Root cause and fix
ADR 0021's pairing reuses an unchanged child regardless of its siblings.
Fix (ADR 0030 §5): when a sibling list changes shape (length, node kind,
or an element's tag/attributes — `siblings_identical`) and the sheet is
sibling-dependent (`SelectorReads::sibling_dependent`), its children leave
the clean set (`unclean_siblings`); descendants still reuse where their
inherited style is unchanged, unless an ancestor compound reads a position
(then the subtrees go).
