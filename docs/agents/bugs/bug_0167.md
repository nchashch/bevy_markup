## Root cause and fix
ADR 0021's adaptive gate turns the pairing off for 16+ builds after one
that reused less than half its specs. A windowed build's specs are only
the band's, so a text change inside the band tripped it easily. For a
windowed UI the pairing also remaps the height model: without a pass the
model cleared and the next content build culled nothing. Fix: a windowed
UI always pairs.
