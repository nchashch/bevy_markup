## Minimal reproduction

Override `broken.css` (falls back to framed default), then `DefaultStylesheet::new(server.load("broken.css"))`.

- Observed: Stays framed forever.
- Expected: Rebuild unstyled.

## Root cause

`load()` on an already-failed asset reads `Loading` for one frame; the build loop `continue`d before computing `dirty` in exactly the frame carrying the change; next frame the failure latch already held.

## Fix

Change signals are computed before deferral; entities dirty while deferred are remembered in a `Local<HashSet<Entity>>` and rebuilt when the sheet resolves.
