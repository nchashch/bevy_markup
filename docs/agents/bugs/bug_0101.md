## Symptoms and repro
`html_ui::inline_var_tracking_gaps_restyle` + `html_ui::translation_inline_var_change_restyles`

## Root cause and fix
The raw text scan stopped at the first non-ASCII byte (var(--café) → --caf); run-level inline styles were never scanned; translation fragments' scans were discarded. Names now come from lightningcss's parsed tokens (InlineStyle::var_names); run_walk scans; fragments merge into the parent accumulator.
