## Symptoms and repro
Both scripts mapped `timeout`'s 124 to success, and neither fuzzer stops
on a crash — a run that found crashes reported green.

## Root cause and fix
Fix: count the crash files (honggfuzz's `hfuzz_workspace/<target>/*.fuzz`,
AFL's `…fuzz_<target>/*/crashes/*`) before and after the run; new ones
fail the script (exit 1). Earlier runs' crashes don't.
