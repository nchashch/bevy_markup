## Symptoms

About 150 nested `<div>`s abort in a debug build (`{{ doc | safe }}` is
enough to deliver it); 1000 nested `<b>` abort in `push_runs`. Every
recursion of the build/update path was unbounded, and each level cloned
the ancestor chain (O(depth²) copying on top).

## Root cause

`collect_node`, `pair_node`, `item_spec`, `spawn_spec`, `update_children`
and `remap_spec_handles` recurse per DOM depth with no bound.

## Fix

`MAX_DOM_DEPTH` = 100: content nested deeper is dropped (warned once,
`warn_overdepth`); the collect and pairing walks take a depth, so every
downstream recursion is bounded (`c07dda7`).
