## Symptoms
`repeat(40000, [a] 1fr)` (track count × count) multiplied into a
debug-build overflow panic; `repeat(40000, auto)` alone did NOT panic
(the count is checked before the loop). Reachable from any stylesheet.
**Guard gap:** the cited test pins the rows-repeat shapes; the
`grid-template-areas` cap (a >1000-row areas string also overflows,
cascade.rs's `parse_areas`) is unguarded — adding one is TODO.

## Root cause and fix

See the commit: `d723f6a` (the tracks cap and the areas cap).
