## Symptoms and repro
`z_order` used `.ok()?` on `GlobalZIndex` and `ZIndex`; most roots have
no `GlobalZIndex`, so every modal tied at `(0, 0)` and the last one
iterated captured the walk. Hidden and `HtmlNoFocus` roots weren't
excluded. G41: `step_linear`'s doc and `#[allow(clippy::too_many_arguments)]`
sat on `z_order`.

## Root cause and fix
Fix: the library's `active_modal` rule — each z component defaults to 0,
visibility as Bevy propagates it, hidden/`HtmlNoFocus` roots skipped —
extracted into a testable `walk_roots`; the attribute and doc are back
on `step_linear`.
