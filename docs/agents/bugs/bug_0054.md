## Symptoms

A `.b .a`×7 `p` selector against 40 nested `.a` ancestors retried every
ancestor combination (~3.8M combinations, ~618 ms for one element, debug
build); each distinct depth was a fresh retry.

## Root cause

`matches_rest(index, ancestors)` recomputed each (compound, offset)
combination with no memo of failures.

## Fix

Failed (compound index, ancestor offset) states are memoized in a
`HashSet` — matching is linear in the ancestor chain (`49525d2`).
