## Symptoms and repro
a scratch harness that sleeps per input fires the ALARM (probe-verified)

## Root cause and fix
libFuzzer's default per-input timeout (1200 s) exceeds a whole nightly campaign (900 s), so a hang consumed the run silently. -timeout=10 added; a later -timeout in the script's args overrides it.
