| field | value |

| Severity | low (matters for user-generated content: an `../..` path in a template or manifest read outside the asset root) |

| Discovered by | code review 2026-10-13 (finding R46, traced) |

## Symptoms

`{% include "../../../etc/passwd" %}` (or an equivalent resource path in a
`*.ftl.ron` manifest) loaded: `read_asset_bytes` doesn't apply Bevy's
`is_unapproved()` check that `AssetServer::load` enforces by default.

## Fix

Both loaders enforce the unapproved-path check on every resolved path,
matching `AssetServer::load`'s default (`402362c`).
