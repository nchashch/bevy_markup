## Symptoms
A cached-Markdown message that had to convert per value (selectors, adjacent placeables) escaped its string arguments again: `O'Brien` displayed as `O&#39;Brien`. The cache path escaped once; the fallback didn't.

## Root cause and fix

The per-value path escaped string args twice (`parse_args` escaped
them; pulldown's code events don't decode entities, so the escaped
text displayed the entities). `15b4255` fixed it by passing the values
RAW — which injected markup on that path (bug review_0003 G01, fixed
by 754f910's escaped-values + decode-in-code-events approach).
