## Root cause and fix
`window_key` was set from every element's handle, windowed or not. Fix:
an item is keyed only when collected with a window (`Item::Container` /
`TextInput { keyed }`, `Block::key`); `update_spec` keeps the key in step
(a kept entity from a window-less first build — before layout — gains its
key; without that it was never measured and never culled), and a cached
spec reuses in a windowed build only if it was built keyed.
