## Symptoms and repro
One container of 4 000 `<p class="x">` children: `settle()` ~13× the
1 000-child time.

## Root cause and fix
Each element copied its preceding siblings (`list[..count].to_vec()`),
and `sibling_positions` recounted the elements per child (allocating a
name per check). Fix (ADR 0030): one `SiblingList` per parent, shared by
`Rc`, with each element holding a `Siblings` view (list + count) and the
list's prefix hashes for the cache key; `sibling_positions` reads the
names once and counts once.
