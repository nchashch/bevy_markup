## Symptoms

`p { --a: var(--a, 1px) var(--a, 1px); width: var(--a) }` recurses ~2³²
times on one element — the app hangs. A doubling reference chain
(`--vN: var(--vN-1) var(--vN-1)`) doubles its output per level: 20 levels
≈ 1.55 s (debug build), 21 ≈ 3 s, … Also breaks the fuzz harness's
never-hang contract.

## Root cause

`substitute` had no memoization and no output budget; the only guard was
`depth > 32`, which bounds recursion depth, not total work.

## Fix

Substitution is memoized per declaration, detects cycles, and stops at a
64 KiB output budget (`e992bf1`).
