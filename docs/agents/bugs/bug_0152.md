## Symptoms and repro
600 bench rows inside `<main>`, windowed, scrolled to 4 000 px: all 1 801
elements built (72 when the same rows sit at the top level). 602 entities
carried a `WindowModel` (one per row container), and every non-windowed
UI's root got one too.

## Root cause and fix
`measure_window_heights` looked the model up on the measured entity's
*parent* (a query `With<HtmlUi>`): only the root's direct children found
it, so nothing deeper was measured, a container's cursor frame
invalidated at its first child, and nothing inside it culled. The lookup's
fallback inserted a `WindowModel` on the parent — every row container,
and (every UI's entities carry `WindowKey`s) the root of every
non-windowed UI. Fix: walk up to the nearest `HtmlUi` and measure into
its model; skip a UI without `HtmlWindowed`.

Found with it: the container cursor counted the container's `margin-top`
twice (`top` already held it and `frame_for` added it again) — invisible
while nested frames culled nothing; fixed (`frame_for(.., Some(0.0), ..)`).
