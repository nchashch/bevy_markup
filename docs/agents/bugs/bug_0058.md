## Symptoms

A code span containing `{{ x }}` rendered the variable's value (or failed
the render); a literal `{% raw %}` inside code failed the load; `let s =
"{%"; // %}` in a fenced block split a string literal. Contradicted ADR
0020 Decision 1 ("code contexts are excluded: text inside code blocks and
code spans is Tera-literal").

## Root cause

The conversion's Tera-aware filter and `separate_statements` had no code
state: `md.rs` only HTML-escaped code text, and `separate_statements`
inserted newlines inside fenced code.

## Fix

The filter tracks code spans and fenced/indented blocks and passes their
content through escaped; `separate_statements` leaves statements inside
them verbatim; `resolve_references` likewise skips includes inside code
(see bug_0067) (`402362c`).
